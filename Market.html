Nita Market

Ketik simbol saham atau crypto, Nita tampilin harga & chart-nya.

Crypto: ketik nama/kode-nya langsung, contoh "btc", "eth", "sol".
Saham global: pakai kode ticker + akhiran bursa. Tanpa akhiran = US (AAPL, TSLA). Indonesia = .JK (BBCA.JK). London = .L, Tokyo = .T, Hong Kong = .HK, Australia = .AX. Index IHSG = ^JKSE.
Alert harga: tiap hasil chart ada tombol Pasang Alert — Nita bakal kirim notifikasi browser kalau harga tembus target (selama tab ini masih kebuka).
Data crypto dari CoinGecko, data saham dari Yahoo Finance lewat proxy publik — gratis, tanpa API key, tapi kadang bisa lambat/gagal karena keduanya layanan gratisan.
